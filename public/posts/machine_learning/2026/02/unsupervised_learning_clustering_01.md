# 비지도 학습
- 정답이 없음
- 질문을 찾는 기술
- 지도학습과 일치할 수 없다
- 군집을 알기 위한 방법

**💡핵심**  
정답(label)을 알려주지 않았음에도 패턴이 보이기 마련이다.
➡ 데이터 자체의 구조

## 1. 개요 및 필요성

### 왜 비지도 학습이 필요할까?
> 현실 데이터의 대부분은 정답(label)이 없다.
- 비지도 학습으로 데이터에서 직접 구조를 발견해야 함

## 2. 그룹화의 근거 (거리 측정 방식)
> 정답이 없는 데이터에서 모델은 무엇을 근거로 그룹을 나눌까?
> → 거리가 가까운 데이터끼리 묶는다.

### Euclidean Distance
두 점 사이의 직선거리

### Cosine Similarity
두 벡터가 이루는 각도의 코사인 값

## 3. 클러스터링 알고리즘

### K-Means
데이터와 평균 사이의 거리를 최소화
1. K개의 중심점을 무작위로 선택
2. 각 데이터와 가장 가까운 중심점을 선택
3. 중심점을 데이터의 평균으로 이동
4. 반복

```
💡 K-Means 가 가장 중요하고, 나머지는 보완재
```

### DBSCAN
- 밀도 기반 군집화
- 스스로 K를 결정
- K-Means와 달리 중심점을 무작위로 선택하지 않음
- 이상치 탐지 가능
  - -1: 노이즈 이상치
- label을 다룰 때 다른 클러스터링과 함께 다루면 안됨

#### DBSCAN의 파라미터
- eps: 이웃으로 판단할 거리
  - 너무 작으면 노이즈가 많아짐
  - 너무 크면 군집이 하나로 합쳐짐
- min_samples: 최소 샘플 수
  - 코어 샘플이 되기 위한 최소 샘플 수
  - 너무 작으면 노이즈가 많아짐
  - 너무 크면 군집이 하나로 합쳐짐
  - 차원 수 * 2 정도로 시작으로 값을 바꿔나갈 수 있음

### GMM
- 확률적 군집화
- 타원형 + 군집이 겹치는 경우
- 각 데이터가 특정 군집에 속할 확률을 계산
- K-Means보다 유연한 군집 경계

### Hierarchical
- 군집 간의 관계를 누적함
- 계층적 구조
- Dendrogram(덴드로그램)을 통해 군집 구조를 시각화
- 스스로 K개를 결정
- K-Means보다 시간이 오래 걸림

## 4. 군집 평가 및 K값 선택법

### 대표적인 K값 선택법
#### Elbow Method
- 군집이 많을 수록 데이터가 더 작게 나뉨
- 그래프를 보고 꺾이는 지점을 찾는다.
- WCSS 감소율
- 군집 내 거리 최소화
- 효율 중심

#### Silhouette Score
- 2부터 n까지 반복 (군집간의 거리를 계산하기 때문에 2부터 시작)
- a: 같은 군집 내 데이터 간 평균 거리
- b: 다른 군집 데이터 중 가장 가까운 군집과의 평균 거리
- 가장 높은 점수
- 품질 중심
> 예) 내 반 친구들과는 얼마나 가깝고, 옆 반 친구들과는 얼마나 먼가? 군집 관계를 점수로 평가

---
### 기타 군집 평가 지표
- **Calinski-Harabasz Index:** 밀도와 분산의 비율 / 값이 높을수록 좋음
- **Davies-Bouldin Index:** 군집 내 거리 / 군집 간 거리 (부적절한 겹침 정도) / 값이 낮을수록 좋음
- **ARI/AMI:** 정답이 있을 때 사용 / 1에 가까울수록 좋음
