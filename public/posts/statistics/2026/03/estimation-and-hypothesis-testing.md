# 추정과 가설검정

## 전체 흐름

통계의 핵심 목표는 **일부를 조사해서 전체를 파악**하는 것이다.
예를 들어, 우리나라 중학생 전체의 평균 키를 알고 싶은데 수백만 명을 다 잴 수는 없다. 그래서 일부만 뽑아서(표본) 전체(모집단)를 추측한다.

이 방법에는 두 가지가 있다.

- **추정**: "우리나라 중학생 평균 키는 얼마일까?" → 숫자나 범위로 대답
- **가설검정**: "우리나라 중학생 평균 키가 165cm라고 할 수 있을까?" → 예/아니오로 대답

---

## 표본을 뽑으면 매번 다른 값이 나온다

100명을 뽑아 키를 재면 평균이 163cm가 나올 수 있다. 다시 다른 100명을 뽑으면 164.5cm가 나올 수 있다. 이렇게 **표본을 뽑을 때마다 평균이 조금씩 달라진다**.

이 표본평균들이 어떤 규칙을 따르는지 알아야 추정과 검정을 할 수 있다.

표본을 n명 뽑았을 때 표본평균의 특성:

- 표본평균의 평균은 실제 모집단 평균(μ)과 같다
- 표본평균이 흩어지는 정도(표준오차)는 σ/√n — n이 클수록 더 모인다

### 중심극한정리 (Central Limit Theorem)

이게 핵심이다. **어떤 집단이든 충분히 많이(보통 30명 이상) 뽑으면, 표본평균들은 정규분포(종 모양) 분포를 따른다.**

예를 들어, 주사위 눈은 1~6 사이 숫자로 균일하게 분포한다. 전혀 종 모양이 아니다. 하지만 주사위를 30번 굴려서 평균을 구하는 걸 수천 번 반복하면, 그 평균들은 종 모양이 된다.

> 주의: 표본 하나하나가 정규분포라는 게 아니다. **여러 표본의 평균들**이 정규분포를 따른다는 뜻이다.

## 통계적 추정

### 점 추정

가장 간단한 방법. 표본 100명의 평균 키가 163cm이면, "전체 평균도 163cm일 것이다"라고 추정하는 것이다. 간단하지만 **얼마나 정확한지 알 수 없다**는 단점이 있다.

### 구간 추정 (신뢰구간)

"정확히 163cm"라고 하는 대신, "아마 161~165cm 범위 안에 있을 거야"처럼 **범위**로 추정하는 방법이다.

실제로 전체 모집단의 표준편차(σ)를 아는 경우는 거의 없기 때문에 보통 **t 분포**를 사용한다.

- $\bar{X}$: 표본평균
- $s$: 표본 표준편차
- $n$: 표본 크기
- $t_{\alpha/2,\, n-1}$: 신뢰수준에 맞는 t 값

신뢰수준을 높이면(95% → 99%) 범위가 더 넓어진다. 더 확실하게 포함하려다 보니 범위가 넓어지는 것이다. **확실성을 높이면 정밀도가 떨어지는 것은 어쩔 수 없다.**

#### 신뢰구간의 올바른 해석

> "이 방법으로 신뢰구간을 100번 구하면, 그 중 약 95번은 실제 평균을 포함한다."

"이 구간 안에 실제 평균이 있을 확률이 95%"라는 해석은 틀렸다. 실제 평균은 이미 어딘가에 고정되어 있는 숫자다. 그 숫자가 이 구간 안에 있거나 없거나 둘 중 하나다. 확률이 적용되는 게 아니다.

### 표본은 몇 명이 필요할까?

처음부터 "오차를 ±2cm 이내로, 95% 신뢰수준으로 맞추고 싶다"고 목표를 정하면, 필요한 표본 크기 n을 미리 계산할 수 있다. 참고로 오차를 절반으로 줄이려면 표본 크기는 4배가 필요하다.

## 가설검정 기초

### 핵심 논리

가설검정은 **수학의 귀류법(반증법)**과 같은 방식이다.

귀류법 예시: "√2가 유리수라고 가정하자 → 그러면 모순이 생긴다 → 따라서 √2는 유리수가 아니다"

가설검정도 마찬가지다:

> "기존 주장(귀무가설)이 맞다고 가정하자 → 그런데 관찰된 결과가 나올 확률(p-value)이 너무 낮다 → 따라서 기존 주장이 틀렸을 가능성이 높다"

- **귀무가설(H₀)**: "차이가 없다", "효과가 없다"는 기존 주장 (항상 등호 포함)
- **대립가설(H₁)**: 연구자가 증명하고 싶은 새로운 주장

대립가설을 직접 증명하는 대신, 귀무가설이 틀렸음을 보여주는 방식으로 간접 증명한다.

### 단측 vs 양측 검정

| 대립가설의 형태   | 사용 상황                            |
| ----------------- | ------------------------------------ |
| μ ≠ μ₀ (양측) | 방향 모름, "그냥 다르다"를 확인할 때 |
| μ > μ₀ (단측)  | "더 크다"를 확인할 때                |
| μ < μ₀ (단측)  | "더 작다"를 확인할 때                |

### p-value와 의사결정

1. 표본에서 검정통계량(Z 또는 t)을 계산한다
2. p-value를 구한다: 귀무가설이 사실일 때, 이 정도로 극단적인 결과가 나올 확률
3. **p-value < α(유의수준, 보통 0.05)** → 귀무가설 기각 → 대립가설 채택
4. **p-value ≥ α** → 귀무가설 기각 실패

예를 들어, p-value가 0.02라면: "귀무가설이 맞다고 가정했을 때, 이런 결과가 나올 확률이 2%밖에 안 된다. 너무 낮다. 귀무가설을 버린다."

> "기각 실패"는 귀무가설이 맞다는 뜻이 아니다. 단지 귀무가설을 틀렸다고 말할 증거가 부족하다는 의미다.

## 주요 검정 방법

상황에 따라 사용하는 방법이 다르다.

### 상황별 선택

| 상황                                        | 선택            |
| ------------------------------------------- | --------------- |
| 한 집단 평균 vs 기준값 (전체 표준편차 앎)   | Z-검정          |
| 한 집단 평균 vs 기준값 (전체 표준편차 모름) | 단일표본 t-검정 |
| 서로 다른 두 집단 평균 비교                 | 독립표본 t-검정 |
| 같은 대상의 전후 비교                       | 대응표본 t-검정 |

### t-분포를 쓰는 이유

전체 표준편차(σ)를 모를 때 표본 표준편차(s)로 대체하면 불확실성이 생긴다. t-분포는 정규분포보다 꼬리가 두꺼워서 이 불확실성을 반영한다. 표본이 많아질수록(자유도 증가) t-분포는 정규분포에 점점 가까워진다.

### 독립표본 t-검정 주의사항

두 집단이 서로 관계없이 독립적이어야 한다. 또한 두 집단의 분산이 비슷한지 먼저 확인해야 한다. 분산이 많이 다르면 **Welch's t-검정**을 쓴다. 이 방법은 분산이 달라도 작동하므로 실무에서 더 안전하다.

### 대응표본 t-검정의 장점

"같은 학생이 수업 전후로 점수가 얼마나 변했는가"처럼 같은 대상의 차이를 분석한다. **사람마다 원래 실력이 다른 것의 영향을 제거**할 수 있어서, 같은 데이터를 분석해도 독립표본 t-검정보다 더 잘 감지해낸다.

## 오류와 통계적 검정력

### 두 가지 실수

가설검정은 완벽하지 않다. 두 종류의 실수가 있다.

|                    | 실제로 H₀이 참                                    | 실제로 H₀이 거짓                           |
| ------------------ | -------------------------------------------------- | ------------------------------------------- |
| **H₀ 기각** | **1종 오류 (α)** — 없는 효과를 있다고 판단 | 올바른 결론                                 |
| **H₀ 채택** | 올바른 결론                                        | **2종 오류 (β)** — 있는 효과를 놓침 |

쉬운 예시:

- **1종 오류**: 죄 없는 사람을 유죄 판결 (억울한 사람이 생김)
- **2종 오류**: 죄 있는 사람을 무죄 판결 (범인이 풀려남)

α를 낮추면(1종 오류를 줄이면) 반대로 β가 올라간다(2종 오류가 늘어난다). 둘을 동시에 줄이려면 표본 크기를 늘리는 것이 방법이다.

### 효과 크기 (Cohen's d)

p-value가 작다고 해서 항상 의미 있는 건 아니다. 표본이 엄청 많으면 아주 작은 차이도 "통계적으로 유의미하다"는 결과가 나온다.

그래서 **차이가 실제로 얼마나 큰지**도 함께 봐야 한다. 이를 효과 크기라고 한다.

$$
d = \frac{\bar{X} - \mu_0}{s}
$$

| Cohen's d | 해석      |
| --------- | --------- |
| 0.2 미만  | 작음      |
| 0.2 ~ 0.5 | 중간      |
| 0.5 ~ 0.8 | 크다      |
| 0.8 이상  | 매우 크다 |

예를 들어, 10,000명을 조사하면 평균 차이가 0.1점밖에 안 되어도 p < 0.05가 나올 수 있다. 하지만 효과 크기(d = 0.05)를 보면 실질적으로는 의미 없는 차이다. p-value만 보고 "유의미하다"고 결론 내리면 안 된다.

### 통계적 검정력

**검정력 = 1 − β** = 실제로 효과가 있을 때 그것을 올바르게 감지할 확률

검정력이 0.8이면 효과가 있는 80%의 경우에서 "있다"고 올바르게 결론 낸다는 뜻이다. 보통 **검정력 0.8 이상**이 좋은 기준이다.

검정력을 높이려면:

- **표본 크기(n)** 를 늘린다
- **효과 크기(d)** 가 클수록 당연히 잘 감지된다
- **표준편차(σ)** 가 작을수록(데이터가 모여 있을수록) 잘 감지된다
- **유의수준(α)** 을 높이면 검정력이 올라가지만, 1종 오류도 함께 증가한다

연구를 시작하기 전에 "검정력 0.8을 달성하려면 표본이 몇 명 필요한가?"를 미리 계산하는 것을 **사전 검정력 분석**이라고 한다. 필요한 것보다 너무 적게 조사해서 놓치거나, 너무 많이 조사해서 비용을 낭비하는 것을 막을 수 있다.

## 정리: 분석 흐름

```
데이터 수집
    ↓
탐색적 분석 (평균, 분산, 분포 확인)
    ↓
목적 결정 ──── 추정이 목적 → 신뢰구간 계산
    │
    └── 검정이 목적 → 귀무/대립가설 설정
              ↓
         검정 방법 선택 (Z / t, 단측 / 양측, 독립 / 대응)
              ↓
         검정통계량 계산 → p-value 산출
              ↓
         p-value < α?  →  기각 여부 판단
              ↓
         효과 크기(Cohen's d) 계산
              ↓
         결론 작성 (통계적 유의성 + 실용적 의미)
```
